НАШ САЙТ — «ТЫ — МОЯ ЛЮБИМАЯ ИСТОРИЯ» ♡
==========================================

КАК ОТКРЫТЬ
1. Распакуйте весь ZIP-архив, сохранив папки.
2. Откройте index.html в Chrome, Opera, Edge или Firefox.
3. На заставке выберите «Открыть под нашу песню» или «Открыть без звука».
4. Встроенный музыкальный плеер позволяет включать, ставить на паузу,
   перематывать песню и менять громкость.
5. Нажмите на любую фотографию, чтобы открыть её в полноэкранном режиме.
   Для навигации работают стрелки клавиатуры и свайпы на телефоне.
6. В галерее есть фильтры «Мы вдвоём», «Твои кадры», «Рисунки».
   Нажмите «Показать ещё», чтобы открыть следующую группу фотографий.
7. Нажмите на конверт, чтобы прочитать личное письмо.

СОДЕРЖИМОЕ
- index.html        — главная страница
- styles.css        — дизайн и анимации
- script.js         — логика и интерактивность
- photos.js         — список фотографий
- assets/photos/    — изображения для полноэкранного просмотра
- assets/thumbs/    — оптимизированные миниатюры
- assets/audio/our-song.mp3 — загруженная вами композиция
- assets/reels/     — два коротких видео из архива
- assets/favicon.svg — иконка страницы

ПОЧЕМУ НЕ ВСЕ ФОТОГРАФИИ ИЗ LOVE.ZIP?
Для открытой романтической страницы выбраны 138 изображений:
42 совместных кадра, 90 повседневных портретов и 6 рисунков.
Из-за приватности не включены интимные кадры и часть посторонних снимков.
Исходный Love.zip не менялся. Фото преобразованы в WebP для быстрой загрузки.

КАК ВЫЛОЖИТЬ САЙТ
Это статический сайт без бэкенда, логинов и баз данных.
Его можно загрузить как статический сайт на GitHub Pages,
Render Static Site, Netlify и другие хостинги.
ВНИМАНИЕ: при публичном размещении фотографии, видео и песня
становятся доступны посетителям сайта. Перед публикацией
обязательно убедитесь в согласии людей на фотографиях и правах
на публичное использование музыки. Если сайт только для двоих,
лучше не публиковать его в открытом доступе.

ЗВУК
Браузеры блокируют автоматическое воспроизведение аудио.
Поэтому включение песни начинается только после нажатия на кнопку.
Вся аудиозапись находится в папке assets и не зависит от интернета.
Для шрифтов есть системные альтернативы, если интернета нет.

ПОКАЗ ПОЛНОЭКРАННОГО ПИСЬМА: откройте письмо и прокручивайте его вниз.
Для закрытия используйте ×, Escape или клик по фону.
